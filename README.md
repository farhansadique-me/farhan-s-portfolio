# Farhan Sadique — Portfolio

A single-page personal portfolio built with **pure HTML, CSS, and JavaScript** (no frameworks, no build step). It showcases my work in design, leadership, public speaking, and data science.

🔗 **Live Demo:** (add your GitHub Pages URL here, e.g. `https://yourusername.github.io/my-portfolio/`)

---

## ✨ Features

- **Intro loader animation** — letter-by-letter name reveal with a scramble effect
- **Sticky particle hero** — a portrait assembles from particles as you scroll (Canvas API)
- **Skills marquee** — infinite scrolling skill chips
- **Services & selected work** — clean list and card layouts
- **Video works grid** — links to Google Drive videos
- **Experience gallery** — certificates and credentials with a lightbox viewer
- **Fully responsive** — mobile-first, with reduced-motion support
- **No dependencies** — everything lives in a single `index.html`

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Markup | HTML5 |
| Styling | CSS3 (custom properties, grid, flexbox, animations) |
| Logic | Vanilla JavaScript (ES5-compatible) |
| Graphics | HTML5 Canvas API |
| Fonts | Google Fonts (Outfit, Instrument Serif, DM Sans, JetBrains Mono) |
